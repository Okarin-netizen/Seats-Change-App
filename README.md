# Seats-Change-App

席替えの希望を集めるアンケートアプリです。サーバーは不要で、HTML ファイルをブラウザで開くだけで動きます。

## 使い方

1. `index.html`（またはそれぞれのページ）をブラウザで開きます。
2. **生徒用（`student.html`）**
   - 出席番号と名前を入力します。
   - 座席表で座りたい席を第1希望 → 第2希望 → 第3希望の順にクリックします。選んだ席をもう一度クリックすると取り消せます。
   - 「提出ファイルを保存」を押すと `seat_05.json`（出席番号5番の場合） のような JSON ファイルがダウンロードされるので、それを先生に提出します。
3. **教員用（`teacher.html`）**
   - 集めた JSON ファイルをまとめてドラッグ＆ドロップ（またはファイル選択）します。
   - 出席番号順の希望一覧と、座席ごとの希望者マップが表示されます。第1希望が2人以上重なっている席は赤枠になります。
   - 「CSVで保存」で一覧を Excel などで開ける CSV に書き出せます。

## 座席の配置

教員用ページの「1. 座席の配置を決める」で配置を作ります。

- 前後の列数と横のマス数（最大 12）を入力します。既定は 6 × 6 です。
- 通路や空きにしたいマスをクリックすると「通路」になります。もう一度クリックすると席に戻ります。
- 配置はそのブラウザに保存され、ページの URL にも入ります。
- 表示される「生徒用リンク」を生徒に配ると、同じ配置の座席表で希望を選べます。

席の呼び方（「前から2列目・左から3番目」など）は、通路を数えずに左から何番目の席かで表示します。

生徒用リンクは `student.html?rows=5&cols=8&off=1-3,2-3` のような形です（`off` は通路にするマスの `列-マス` 番号）。生徒が自分の端末で開けるよう、GitHub Pages など生徒がアクセスできる場所にファイルを置いてください。

## 提出ファイルの形式

```json
{
  "app": "seats-change-app",
  "version": 1,
  "number": 5,
  "name": "山田太郎",
  "rows": 6,
  "cols": 6,
  "off": ["1-3", "2-3"],
  "choices": [
    { "rank": 1, "row": 1, "col": 3 },
    { "rank": 2, "row": 2, "col": 4 },
    { "rank": 3, "row": 4, "col": 1 }
  ],
  "submittedAt": "2026-10-16T07:40:00.000Z"
}
```

`row` / `col` は通路も含めたマスの位置（1 始まり）で、`row: 1` が最前列、`col: 1` が教室の左端です。`off` は通路にしたマスです。
