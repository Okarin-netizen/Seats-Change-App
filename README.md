# Seats-Change-App

席替えの希望を集めるアンケートアプリです。サーバーは不要で、HTML ファイルをブラウザで開くだけで動きます。

## 使い方

1. `index.html`（またはそれぞれのページ）をブラウザで開きます。
2. **生徒用（`student.html`）**
   - 出席番号と名前を入力します。
   - 座席表で座りたい席を第1希望 → 第2希望 → 第3希望の順にクリックします。選んだ席をもう一度クリックすると取り消せます。
   - 「提出ファイルを保存」を押すと `seat_05.json`（出席番号5番の場合） のような JSON ファイルがダウンロードされるので、それを先生に提出します。
3. **教員用（`teacher.html`）**
   - 集めた JSON ファイルをまとめてドラッグ＆ドロップ（またはファイル選択）します。
   - 出席番号順の希望一覧と、座席ごとの希望者マップが表示されます。第1希望が2人以上重なっている席は赤枠になります。
   - 「CSVで保存」で一覧を Excel などで開ける CSV に書き出せます。

## 座席表の大きさ

既定は 6列 × 6人（前後 6 列、横 6 人）です。URL に `?rows=5&cols=7` のように付けると変えられます（最大 12）。

- `rows`：前後の列数（1 が教卓側）
- `cols`：横の人数（1 が教室の左側）

例：`student.html?rows=5&cols=7` を生徒に配れば、5 × 7 の座席表になります。教員用ページは画面上で大きさを変えられ、読み込んだファイルに合わせて自動で広がります。

## 提出ファイルの形式

```json
{
  "app": "seats-change-app",
  "version": 1,
  "number": 5,
  "name": "山田太郎",
  "rows": 6,
  "cols": 6,
  "choices": [
    { "rank": 1, "row": 1, "col": 3 },
    { "rank": 2, "row": 2, "col": 4 },
    { "rank": 3, "row": 4, "col": 1 }
  ],
  "submittedAt": "2026-10-16T07:40:00.000Z"
}
```

`row` / `col` は 1 始まりで、`row: 1` が最前列、`col: 1` が教室の左端です。
