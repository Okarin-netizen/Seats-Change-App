# Seats-Change-App

席替えの希望を集めるアンケートアプリです。サーバーは不要で、HTML ファイルをブラウザで開くだけで動きます。

## 使い方

希望は1人1席（第1希望のみ）です。ほかの人と希望がかぶらなかった人はその席に決定し、かぶった人だけで2回目、3回目…と調査を続けます。

1. **教員用（`teacher.html`）で準備**：座席の配置を決め、「生徒用リンク」を生徒に配ります。
   - 先に席を決めておきたい生徒がいるときは、「5. 座席表」の「先生が生徒を配置する」にチェックを入れ、席をクリックして出席番号と名前を入れます。配置した席は生徒用リンクで選べなくなり、その生徒の提出は使われません。配置済みの席をもう一度クリックすると取り消せます（途中の回でも使えます）。
2. **生徒用（`student.html`）**：出席番号と名前を入力し、座りたい席を1つクリックして「提出ファイルを保存」を押します。`seat_r1_05.json`（第1回・出席番号5番の場合）のようなファイルが保存されるので、先生に提出します。
3. **教員用で集計**：集めたファイルをまとめてドラッグ＆ドロップすると、一人ひとりの結果が「決定」か「かぶり」で表示されます。座席表では、決定済みの席は灰色、今回決定は緑、かぶりは赤枠です。
4. **次の回へ**：「決定して次の調査へ進む」を押すと「決定」の人の席が確定します。決定済みの席を選べなくした次の回の生徒用リンクが出るので、席が決まっていない人に配り、2〜3 をくり返します。
5. 決定済みの席は「6. 決定済みの席」の一覧で変更できます。
   - **席を変える**：押してから座席表で移動先の席をクリックします。決定済みの人がいる席を選ぶと、2人の席を入れ替えます。「やめる」で中止できます。
   - **取り消す**：その人の席を空けます。取り消した人は、次の回の調査でもう一度選べます。
6. 決定済みの席の一覧は「CSVで保存」で書き出せます。「最初からやり直す」で第1回に戻ります。

- 調査の進み具合（何回目か・決定済みの席・名簿・条件）は教員のブラウザに保存されます。別のパソコンで続けるときは「7. 保存と引き継ぎ」の「進み具合を書き出す」で JSON ファイルにし、別のパソコンで「進み具合を読み込む」で開きます。
- 違う回のファイルや、すでに席が決まった人のファイルは読み込み時に除外され、理由が表示されます。
- 操作をまちがえたときは、画面右下の「元に戻す」（または Ctrl+Z）で1つずつ戻せます。戻せるのはページを開いている間だけです。

## 便利な機能

- **かぶった席をくじで決める**（4. 今回の結果）：かぶった席ごとに1人をくじで決定にします。くじ番号が表示されます。引き直すときは「元に戻す」を押してからもう一度くじを押します。提出を読み込み直すと、くじの結果は消えます。
- **第2希望**（2. の「調査の設定」）：「第2希望も集める」にすると、生徒は第1希望と第2希望を選べます。第1希望がかぶった人は、第1希望でだれも選んでいない席なら第2希望に決まります。かぶった人のうちほかの人が第2希望に決まって1人だけ残ったときは、その人が第1希望の席に決まります。
- **人気の席**：前の回でかぶって決まらなかった席を、次の回の生徒用ページに「人気」として表示します（名前は出ません）。
- **名簿**（名簿と配慮の条件）：「出席番号 名前」を1行ずつ貼り付けて保存すると、まだ席が決まっていない人数、まだ提出していない人、名簿と番号・名前が合わない提出（「要確認」）がわかります。名簿は生徒用リンクには入りません。
- **配慮の条件**：
  - **前の席**：出席番号と「前から何列目まで」を入れて足します。表の「専用リンクをコピー」で、その生徒だけに配るリンクが作れます（条件に合う席だけ選べます）。条件に合わない提出は「選べない席」になります。
  - **離す**：2人の出席番号を入れて足します。2人が左右（通路をはさまない）か前後で隣になりそうなときは、結果の下と「決定して次の調査へ進む」の確認に注意が出ます。
- **前回と同じ席を選べなくする**：「最初からやり直す」のときに今の座席を「前回の席」として残すか、前の席替えで書き出したファイルを「前回の席として読み込む」で入れておき、2. の設定で選びます。生徒用リンクに出席番号と前回の席だけが入ります（名前は入りません）。
- **座席表の向き・印刷・発表**（5. 座席表）：「生徒から見た向き」と「教卓から見た向き」を切り替えられます。「座席表を印刷」で決定済みの席を A4 横1枚に印刷（PDF 保存も可）できます。「発表モード」は教室で投影して、1人ずつ席を発表します（Space・→ で次へ、← で戻る、Esc で終わる）。
- **CSV** には「前から(列)」「左から(番目)」の列も入ります。

## Google スプレッドシートで提出を受け取る（任意）

設定すると、生徒は「提出する」を押すだけで提出でき、先生は教員用ページの「スプレッドシートから読み込む」で集計できます。ファイルの受け渡しは不要になります。設定しなければ、これまでどおりファイルでやり取りします。

### 準備（最初に1回だけ）

1. Google ドライブで新しいスプレッドシートを作ります（名前は何でも構いません）。
2. メニューの **拡張機能 → Apps Script** を開きます。
3. 最初から入っているコードをすべて消し、このリポジトリの [`gas/Code.gs`](gas/Code.gs) の中身を貼り付けます。
4. 上の方にある `const TEACHER_KEY = "ここを合言葉に変える";` の `ここを合言葉に変える` を、自分だけが知っている合言葉に書き換えて保存します（生徒には教えないでください）。
5. 右上の **デプロイ → 新しいデプロイ** を押し、歯車アイコンから **ウェブアプリ** を選びます。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（生徒が Google にログインしなくても提出できるようにするため）
6. **デプロイ** を押します。初回は「アクセスを承認」を求められるので、自分のアカウントを選んで許可します（「このアプリは Google で確認されていません」と出たら「詳細」→「（プロジェクト名）に移動」）。
7. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピーします。
8. 教員用ページの「Google スプレッドシートで提出を受け取る（設定）」を開き、URL と合言葉を入れて「保存して接続を確かめる」を押します。

「つながりました」と出れば完了です。生徒用リンクが、提出がスプレッドシートに届くリンクに変わります。

### 使い方

- 生徒は生徒用リンクを開き、席を選んで「提出する」を押します。提出は「提出」シートに1行ずつたまります。
- 先生は「スプレッドシートから読み込む」を押すと、今回の回の提出がまとめて読み込まれます。同じ人が何度か出したときは最後の提出を使います。
- 送信に失敗したときは、生徒の画面にファイルを保存するボタンが出るので、そのファイルを受け取って読み込めます。

### 注意

- 生徒の名前と希望は、先生の Google アカウントのスプレッドシートに保存されます。学校のルールで問題ないか確認してください。
- 提出用 URL を知っていれば誰でも提出できます（ほかの人の出席番号で出すこともできます）。気になる提出は、スプレッドシートの受信日時と合わせて確認してください。
- `gas/Code.gs` を書き換えたときは、**デプロイ → デプロイを管理** から新しいバージョンとしてデプロイし直してください。
- 第2希望を使うときは、新しい `gas/Code.gs`（第2希望の列があるもの）に貼り替えてデプロイし直してください。今の「提出」シートはそのまま使えます（右端に第2希望の2列が増えます）。

## 座席の配置

教員用ページの「1. 座席の配置を決める」で配置を作ります。

- 前後の列数と横のマス数（最大 12）を入力します。既定は 6 × 6 です。決定済みの席ができた後は、配置は変更できません。
- 通路や空きにしたいマスをクリックすると「通路」になります。もう一度クリックすると席に戻ります。
- 配置はそのブラウザに保存され、ページの URL にも入ります。
- 表示される「生徒用リンク」を生徒に配ると、同じ配置の座席表で希望を選べます。

席の呼び方（「前から2列目・左から3番目」など）は、通路を数えずに左から何番目の席かで表示します。

生徒用リンクは `student.html?rows=5&cols=8&off=1-3,2-3` のような形です（`off` は通路にするマスの `列-マス` 番号）。生徒が自分の端末で開けるよう、GitHub Pages など生徒がアクセスできる場所にファイルを置いてください。

## 提出ファイルの形式

```json
{
  "app": "seats-change-app",
  "version": 1,
  "round": 1,
  "number": 5,
  "name": "山田太郎",
  "rows": 6,
  "cols": 6,
  "off": ["1-3", "2-3"],
  "choice": { "row": 1, "col": 4 },
  "submittedAt": "2026-10-18T01:00:00.000Z"
}
```

`row` / `col` は通路も含めたマスの位置（1 始まり）で、`row: 1` が最前列、`col: 1` が教室の左端です。`off` は通路にしたマス、`round` は何回目の調査かです。

第2希望を選んだときは `"choice2": { "row": 2, "col": 2 }` も入ります。

生徒用リンクには `round`（何回目か）と `taken`（決定済みの席）も入ります。例：`student.html?rows=6&cols=6&round=2&taken=1-6,2-2`

設定によっては次も入ります：`second=1`（第2希望も集める）、`hot`（人気の席）、`prev=5:1-3,6:2-4`（出席番号ごとの前回の席）、`maxrow=2&num=5`（前の席の条件がある生徒の専用リンク）。
