# 要求の一覧（席替えアンケート）

IPA「AI時代の要求管理ハンドブック」の考え方で、この制作物の要求をまとめた台帳です。
2026年11月23日の点検で書き起こしたものなので、状態はすべて「候補」です。
すでに実装されているものも、内容を確かめて「承認」にするまでは「候補」のままにしています。

## 目的

- 何のため：席替えで生徒の希望をできるだけ生かし、決め方を生徒に説明できるようにする。先生の集計の手間を減らす
- 誰のため：担任（教員用ページ）と、生徒（自分の端末の生徒用ページ）
- 成功の目安：1クラス分の席が、授業の中の決めた時間内に決まる。結果について生徒に決め方を説明できる（数値は要検討）

| ID | 条件 | 確かめ方 | 結果（日付） |

| SEK-AC2 | 1クラス分（例：34人）の提出を読み込むと、決定・かぶり・未提出の数が名簿と一致する | 擬似データでのテスト |  |

## ルール要求

学校や法令のきまりを、このアプリで守る形に直したものです。

| きまり | 要件 | 確かめ方 |
|---|---|---|
| 個人情報は学校が認めた場所に置く | スプレッドシートは学校のアカウントで作る | 手順書 |
| 不特定多数に公開しない | ウェブアプリを学校のドメイン内で公開できるか確かめ、できるなら手順の最初にする | 設定の確認 |
| 必要な間だけ保存する | 席替えが終わったら提出のシートを消す | 手順書 |
| 生徒の事情に関わる情報は見られる人を限る | 配慮の条件は教員用ページだけに置き、印刷や発表モードに出さない | 画面の確認 |

## データ

| データ | 中身 | 保存場所 | 見られる人 | 消し方・期間 |
|---|---|---|---|---|
| 提出 | 回・出席番号・名前・希望の席・日時 | 生徒が保存したJSON／先生のスプレッドシート | 先生 | 未定（案：席替えが終わったら消す） |
| 進み具合 | 回・決定済みの席・名簿・条件 | 先生のブラウザと、書き出したJSON | 先生 | 「最初からやり直す」。名簿と条件の消し方は画面で要確認 |
| 配慮の条件 | 前の席の列、離す二人の出席番号 | 先生のブラウザ（専用リンクには番号と列だけ） | 先生 | 未定 |
| 前回の席 | 出席番号と席 | 先生のブラウザ、生徒用リンク | 先生・リンクを開いた生徒 | 次の席替えまで |

## 書き方のきまり

- 状態は「候補 → 承認 → 実装中 → 検証済み」と進めます。やめたものは「見送り」、決めかねているものは「保留」にします。
- 要求を変えたら、変更の履歴に日付と理由を書きます。IDは使い回しません。
- 受入条件を確かめたら、結果の欄に日付と結果を書きます。
